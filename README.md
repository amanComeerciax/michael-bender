# Michael Bender — Executive Portfolio (Next.js)

An executive portfolio website for **Michael Bender**, Chief Executive Officer at **RCD Espanyol de Barcelona Academy South Africa** and **IberCup South Africa**, governmental diplomatic envoy, and international corporate marketing executive.

## Features & Highlights

- **Original, Uncropped Imagery**:
  - `michael-bender-award.jpg`: Michael Bender honored at the IX Annual RCDE Academies Meeting in Barcelona, Spain with the club crest and official recognition.
  - `rcde-academy-squad.png`: Full panoramic view of hundreds of youth players and coaching staff at King David Victory Park stadium.
  - `campaign-rockets-1.png` & `campaign-rockets-2.png`: Luxury lifestyle and gastronomy creative direction for Rockets.
  - `campaign-values.png`: Automotive diagnostic brand campaign ("Values").
  - **Full-Resolution Lightbox**: Clicking any image opens a zero-cropping modal viewer.
- **Deep Executive Narrative**:
  - 30+ years in international football governance (FIFA 2010 World Cup executive, 1998 France, IberCup, Donosti Cup).
  - First official LaLiga club academy in South Africa (RCD Espanyol de Barcelona Academy SA).
  - Largest international youth tournament in Africa (IberCup SA: 220 teams, 1,000+ matches, 35,000+ attendees).
  - Diplomatic statecraft: SA Presidential working group (eThekwini sports tourism), Gauteng envoy to Catalonia Generalitat Minister of Sport, Malaga-Durban mayoral accord.
  - Blue-chip marketing leadership: Ster-Kinekor (PlayStation, Sony Pictures, Paramount), DDB SA, Think Advertising CEO (8 years).
  - Academic masterclasses: Wits Business School (MBA Honours), Vega, AFDA.
  - Principles of leadership: "Culture before results", "Structure above all else", "Purpose beyond the pitch".
- **Tech Stack**:
  - Next.js 15 (App Router)
  - React 19
  - Vanilla CSS design system with Catalan Royal Blue, Gold Champagne, and Midnight Slate palettes
  - Lucide React icons
  - Fully responsive across desktop, tablet, and mobile devices

## Running the Project

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the live website.
